# HushType 0.5.18 Preview 16

- 监听浮窗支持拖动，靠近屏幕底部默认位置时吸附并提供触觉反馈；拖动时显示玻璃占位提示，靠近重合位置后逐渐淡出。
- macOS 26 的占位提示使用控制中心风格玻璃，并在不抢占键盘焦点的情况下保持完整外观。
- 优化调试页侧栏展开、收起动画，减少宽度变化时重复构造整张表单的开销。
- 修复浅色模式下侧栏右侧顶部的阴影接缝，保持顶栏按钮与拖动区域的交互顺序。
- Preview 调试页可调整吸附半径和淡出曲线。浮窗自定义位置仅在本次运行期间保留，重启后回到默认位置。

上述占位效果、动画流畅度和浅色阴影修复已人工验收。已有听写、原生历史和顶部滚动模糊行为保持。

已知限制：既有顶栏下沿拖动范围、启动顶栏延迟和部分设备边界继续留待后续处理；本版不包含云端听写或字幕功能恢复。
