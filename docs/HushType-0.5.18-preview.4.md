# HushType 0.5.18 Preview 4

本预览版本继续修复 iPhone 麦克风在 Mac 端关闭蓝牙后的断开漏报。

- 首个有效音频到达后，记录真实 PCM buffer 的持续活动时间。
- 即使 iPhone endpoint 仍留在 CoreAudio 列表并报告存活，只要音频流连续 2.5 秒停止，便统一显示“连接断开”。
- 心跳只判断 buffer 是否到达，不判断音量；安静和零电平不会被当作断开。
- 心跳仅用于 F5 听写且按当前候选会话隔离，不改变启动超时、自动回退或实时字幕路径。

请在 iPhone 麦克风已进入“监听中”后，从 Mac 控制中心关闭蓝牙，等待约 2.5–3 秒验收断开提示。
