# HushType 0.5.18

本次正式版整合本地听写、字幕、处理配置与词库管理，并改善窗口交互和输入稳定性。

- **处理配置**：分别为听写和字幕选择输入来源、语音模型、识别语言、整理规则与本地 AI 处理。运行中的任务保留启动时的配置，编辑用于下一次任务。
- **随处编辑**：配置与词库使用可调整宽度的右侧玻璃面板；配置支持自动保存，也可关闭自动保存后手动保存。标题旁可搜索和切换编辑对象。
- **词库管理**：支持多个命名词库、规则编辑和替换预览；配置可以不选、单选或多选词库，也允许删除默认词库。
- **本地处理**：支持缓存模型驱动的校对与中文翻译。语音和文字模型在本地排队运行；任务不会因模型缺失而悄悄回退到另一模型。
- **字幕与音频**：改进共用音频输入、停止收尾和再次启动；可以为应用音频选择“无”。未选择来源时不发起录音或权限请求。
- **快捷键与导航**：支持自定义快捷键，侧栏可长按排序；前进和后退按实际访问历史导航。
- **输入与历史**：修复 HushType 自身输入框和 Spotlight 的听写焦点问题；增强历史筛选及字幕会话记录。
- **窗口与性能**：减少本地化字符串重复解析，保留实时排版和完整动效；修正面板安全区、按钮运动起点、顶栏通透遮罩与间距。

## 安装与更新

适用于 Apple Silicon，最低 macOS 15。下载 `HushType-0.5.18.zip`，解压后将 HushType.app 放入“应用程序”；已有用户也可通过应用内更新检查升级。

沿用固定自签名身份，未经 Apple 公证。模型、配置、词库和历史位于应用包之外，正常替换应用包会保留。由旧临时签名版本升级时，macOS 可能要求重新授予权限。

本次发布不包含新的云端服务或 iOS 客户端更新。
