# HushType 0.5.18 Preview 15

- macOS 26 设置侧栏接入系统滚动边缘效果；右侧保留自适应顶部模糊，随导航、搜索和侧栏按钮的位置调整挖孔。
- 减少顶部遮罩重复生成和逐行绘制分配，复用布局跟踪计时器，保持滚动开始及时响应、停止后平滑收尾。
- Preview 调试页可分别调整左侧系统效果和右侧模糊参数，并提供侧栏滚动测试控制。
- 设置项按功能折叠分组；默认临时剪贴板输入在粘贴派发后等待约 500ms，再在剪贴板仍由本次输入持有时恢复原内容，保留期间的新复制。识别文字可从历史记录手动复制。
- 另提供 Unicode 键盘输入选项，分段大小和间隔可调；输入失败时停止，不自动切换输入方式。

当前候选的视觉与省电模式手感已人工接受。原生历史列表、行高及滚动锚点保持现有行为。

已知限制：顶栏下沿部分空白位置的拖动、启动顶栏延迟继续暂缓。此前左顶栏动画黑块在后续试用中未复现，根因仍未确认；Unicode 输入在各目标应用中的兼容性仍需实际使用确认。
